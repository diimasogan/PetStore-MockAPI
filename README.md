# PetStore Mock API — Boomi

Small Boomi Web Services demo implementing `Get Pet` and `Create Pet` endpoints with a JSON profile.

📄 **Documentation:** [English](https://diimasogan.github.io/PetStore-MockAPI/docs/PetStore-Mock-API-Documentation.html) · [Bahasa Indonesia](https://diimasogan.github.io/PetStore-MockAPI/docs/id/PetStore-Mock-API-Dokumentasi.html)

🖥️ **Live console mockup:** https://diimasogan.github.io/PetStore-MockAPI/portal/ — try both endpoints in the browser,
see the Boomi process path each request takes, and play with a small pet-shop demo built on the API.

| Path | What |
|---|---|
| `active-development/process/` | API & sub-processes |
| `active-development/connector-action/` | Web Services Server operations |
| `docs/` | Documentation EN + ID (generated by `docs/_source/build_docs.py`) |
| `portal/` | Static console mockup (`index.html`, `style.css`, `app.js`) |
| `active-development/profile.json/` | Pet JSON profile |

Copy `.env.example` to `.env` and fill in your Boomi credentials (never committed).
